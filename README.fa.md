# پنل NoTrack

**نسخهٔ 0.1.0 — پیش‌انتشار** · [English](README.md) · [امنیت](SECURITY.md) · [تغییرات](CHANGELOG.md) · [مجوز MIT](LICENSE)

پنل مرورگری برای **یک اپراتور** و دروازه‌ای با **زیرمجموعهٔ متنی** قالب Chat Completions اوپن‌ای‌آی، روی بک‌اند گفت‌وگوی وب NoTrack. پروژه مستقل و غیررسمی است؛ وابستگی رسمی به NoTrack یا OpenAI ندارد. بک‌اند ممکن است مستندنشده باشد و بدون اطلاع تغییر کند. هویت مدل، معماری پایه، نسخه، دسترس‌پذیری یا خروجی بدون فیلتر تضمین نمی‌شود. این پنل با API رسمی و پولی NoTrack یکسان نیست.

## نصب سریع در لینوکس و macOS

پیش‌نیازها: Git، Bash، **Python 3.10 یا جدیدتر**، ماژول‌های `venv` و `ensurepip`. اگر موجود نیستند ابتدا با ابزار سیستم‌عامل خود نصب کنید. مسیر پیش‌فرض نصب هیچ `apt` یا `sudo` اجرا نمی‌کند، بستهٔ سیستمی و سرویس نصب نمی‌کند و سرور را خودکار راه نمی‌اندازد.

```bash
git clone https://github.com/HELBOYCODER/notrack-panel
cd notrack-panel
bash install.sh
./run.sh
```

نشانی <http://127.0.0.1:8080/> را باز کنید. در پنجرهٔ ورود **HTTP Basic مرورگر**:

- نام کاربری: **`panel`**
- رمز عبور: مقدار **`PANEL_TOKEN`** از فایل محلی `.env`

نصاب توکن تصادفی امن می‌سازد و `.env` را با دسترسی **600** ذخیره می‌کند؛ **توکن چاپ نمی‌شود**. فقط با ویرایشگر محلی، مثلاً `nano .env`، آن را بخوانید. در چت، گزارش خطا، تصویر یا لاگ منتشرش نکنید. اجرای دوبارهٔ نصاب توکن موجود را حفظ می‌کند؛ اگر خالی است، محلی یک توکن تصادفی قوی تنظیم کنید. توقف سرور: **Ctrl+C**.

اجرا در محیط مجازی `.venv`، با یک worker و فرمان Uvicorn شامل `--env-file .env` انجام می‌شود؛ `python-dotenv` برای خواندن فایل لازم است. پیش‌فرض **`HOST=127.0.0.1`** و **`PORT=8080`** است. متغیر محیطی از قبل تنظیم‌شده بر مقدار `.env` اولویت دارد. چند worker، چند نمونهٔ سرور یا چند کانتینر روی دادهٔ مشترک اجرا نکنید.

### سرویس اختیاری systemd؛ فقط لینوکس

فقط با انتخاب صریح، از حساب **فعلی غیرروت** و بدون sudo:

```bash
bash install.sh --service
systemctl --user status notrack-panel
journalctl --user -u notrack-panel -f
# توقف و غیرفعال‌سازی:
systemctl --user disable --now notrack-panel
```

از سرویس کاربری systemd استفاده می‌شود؛ حساب اختصاصی یا سرویس سراسری ساخته نمی‌شود. گزینه‌های `NoNewPrivileges=true`، `PrivateTmp=true` و `UMask=0077` فعال‌اند و `.env` دسترسی 600 دارد. به user manager فعال و پشتیبانی namespace نیاز است؛ اگر موجود نیست `./run.sh` را اجرا کنید. برای اجرا قبل از ورود کاربر ممکن است مدیر سیستم نیاز به فعال‌کردن lingering داشته باشد؛ نصاب این کار را نمی‌کند.

### ویندوز؛ نصب دستی در PowerShell

Python 3.10+ لازم است؛ نصاب Bash برای لینوکس/macOS است. مخزن را clone کنید و وارد پوشه شوید، سپس:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python -c "from pathlib import Path; import secrets; p=Path('.env'); p.exists() and exit('Existing .env preserved; edit it locally'); p.write_text('PANEL_TOKEN='+secrets.token_urlsafe(32)+'\nHOST=127.0.0.1\nPORT=8080\n', encoding='utf-8')"
.\.venv\Scripts\python -m uvicorn app:app --env-file .env --host 127.0.0.1 --port 8080 --workers 1
```

قبل از اجرا، دسترسی فایل `.env` و پوشهٔ `data/` را با ACL ویندوز به حساب خود محدود کنید؛ حالت POSIX 600 جایگزین ACL ویندوز نیست. توکن را در ویرایشگر محلی بخوانید و با همان نام کاربری `panel` وارد شوید.

## احراز هویت و داده‌های خصوصی

تمام مسیرهای **`/api/*` و `/v1/*`**، حتی health و فهرست مدل‌ها، به توکن نیاز دارند. تنظیم نبودن یا خالی بودن `PANEL_TOKEN` دسترسی آزاد ایجاد نمی‌کند؛ سامانه باید بسته بماند.

- مرورگر: Basic با نام `panel` و رمز توکن.
- برنامه‌ها: هدر **`Authorization: Bearer <PANEL_TOKEN>`** با همان توکن؛ کلید دلخواه پذیرفته نیست. توکن را داخل URL نگذارید.
- پنل **چندمستاجری نیست**؛ همهٔ دارندگان توکن به تاریخچه و مدیریت نشست‌های مشترک دسترسی دارند. شناسهٔ نشست، مرز دسترسی کاربری نیست.
- هویت وب و نشست‌ها در `data/` **بدون رمزگذاری و به‌صورت متن ساده** می‌مانند. `.env` و دادهٔ محلی در Git نادیده گرفته و از ساخت Docker حذف می‌شوند؛ پشتیبان‌ها را نیز محافظت کنید. پیش از انتشار، فایل‌های staged را بررسی کنید. پیام‌ها به سرویس بالادستی هم فرستاده می‌شوند و ممکن است آنجا بمانند.
- اتصال را روی loopback نگه دارید. برای دسترسی راه دور HTTPS و ترجیحاً لایهٔ کنترل دسترسی اضافه لازم است؛ Basic صرفاً base64 است، نه رمزگذاری. توکن را روی HTTP عمومی نفرستید.

## API و محدودیت سازگاری

نشانی محلی پایه: `http://127.0.0.1:8080/v1`. مسیرهای اصلی: `GET /v1/models` و `POST /v1/chat/completions`. شناسه‌های موجود را از فهرست مدل‌ها با احراز هویت بخوانید. نمونهٔ کلاینت اختیاری OpenAI؛ بستهٔ `openai` را جداگانه در محیط کلاینت نصب کنید:

```python
import os
from openai import OpenAI

client = OpenAI(base_url="http://127.0.0.1:8080/v1",
                api_key=os.environ["PANEL_TOKEN"])
first = client.chat.completions.create(
    model="notrack-uncensored",
    messages=[{"role": "user", "content": "My dog is Biscuit."}],
)
print(first.choices[0].message.content)
second = client.chat.completions.create(
    model="notrack-uncensored",
    messages=[{"role": "user", "content": "What is my dog's name?"}],
    extra_body={"session_id": first.session_id},
)
```

کلاینت خودکار فایل `.env` پروژه را نمی‌خواند؛ توکن را امن در محیط کلاینت بارگذاری کنید و در کد ننویسید. `session_id` افزونهٔ پنل است، نه فیلد استاندارد OpenAI. در حالت `stream=True` ممکن است رویداد فرادادهٔ نشست کنار قطعه‌های متن ارسال شود؛ کلاینت باید آن را تحمل کند.

- فقط پیام متنی با نقش‌ها و محتوای پشتیبانی‌شده، انتخاب مدل، جریان پاسخ و `session_id` پشتیبانی می‌شود؛ تصویر، صدا، ابزار، function calling و تضمین خروجی ساختاریافته وجود ندارد.
- `tools`، `max_tokens`، `temperature` و پارامترهای پشتیبانی‌نشده **رد می‌شوند**؛ نادیده گرفته نمی‌شوند. پیش‌فرض‌های SDK یا فریم‌ورک خود را بررسی کنید.
- بالادست شمارش قابل‌اعتماد توکن نمی‌دهد؛ **`usage` حذف می‌شود** و از تعداد کاراکتر عدد جعلی ساخته نمی‌شود. مناسب صورتحساب توکنی نیست.
- **حالت نشست‌دار:** `session_id` برگشتی را همراه پیام بعدی بفرستید تا گفت‌وگوی بالادستی ادامه یابد.
- **حالت بدون نشست:** تاریخچه را در `messages` بفرستید و `session_id` را حذف کنید. تاریخچه باید در بودجهٔ دستورها جا شود؛ **تاریخچهٔ بلند خطا می‌دهد و بی‌صدا بریده نمی‌شود**. خودتان خلاصه‌سازی کنید یا نشست‌دار کار کنید.

سقف‌های محافظه‌کارانهٔ محلی، براساس مشاهده، **4000 کاراکتر ورودی** و حدود **1980 کاراکتر سیستم/دستورها** شامل تاریخچهٔ ادغام‌شده هستند؛ نه تعداد توکن و نه تضمین دقیق محدودیت بالادست. درخواست کوچک‌تر نیز ممکن است رد شود.

فقط **یک هویت ماندگار صادرشده توسط سرور وب** نگهداری می‌شود. درخواست‌ها در یک فرایند **سراسری و سریالی** اجرا می‌شوند؛ چرخش UID، مزرعهٔ هویت یا دورزدن سهمیه وجود ندارد. خطای محدودیت نرخ به فراخواننده برمی‌گردد؛ با هویت تازه دور زده نمی‌شود. پیش از تلاش مجدد صبر کنید و مقررات بالادست را رعایت کنید. `PANEL_PACE` تضمین توان عملیاتی نیست.

برچسب‌های قدیمی و آزمایشی **A/B** و نام‌هایی مانند Minimax یا ChatGPT فقط برچسب مسیریابی‌اند؛ هویت ارائه‌دهنده، معماری یا نسخه را اثبات نمی‌کنند. **B قبلاً ناموفق بوده** و دسترس‌پذیری آن یا دیگر گزینه‌ها تضمین نیست. نام `notrack-uncensored` هم تضمین خروجی بدون فیلتر نیست.

## جایگزین Docker

Docker Engine و افزونهٔ Compose لازم است. **ساخت و اجرای Docker در این محیط آزموده نشده است** و وجود image منتشرشده ادعا نمی‌شود. بعد از clone و ورود به پوشه، بدون نصب محلی برنامه:

```bash
umask 077
python3 -c 'from pathlib import Path; import secrets; p=Path(".env"); p.exists() and exit("Existing .env preserved; edit locally"); p.write_text("PANEL_TOKEN="+secrets.token_urlsafe(32)+"\nHOST=127.0.0.1\nPORT=8080\n")'
chmod 600 .env
docker compose up --build -d
docker compose logs -f panel
# توقف با حفظ داده:
docker compose down
```

توکن چاپ نمی‌شود؛ در ویرایشگر محلی بخوانید. پورت فقط روی **127.0.0.1:8080 میزبان** منتشر می‌شود. اتصال `0.0.0.0` داخل کانتینر است. کانتینر با **UID/GID 10001** اجرا می‌شود و `/app/data` در volume نام‌دار `panel-data` ذخیره می‌شود؛ volume تازه مالکیت پوشهٔ image را به ارث می‌برد. آن را با bind mount روت‌مالک جایگزین نکنید؛ volume موجود یا bind mount باید برای 10001:10001 آماده شود. `docker compose down -v` **داده و هویت را حذف می‌کند**؛ ابزار بازنشانی سهمیه نیست. فقط یک نمونه اجرا کنید. توکن خالی در Compose رد می‌شود؛ `.env` داخل image نیست، اما مدیر Docker می‌تواند رازهای کانتینر را ببیند.

## تونل اختیاری HTTPS

فقط اگر **خودتان قصد انتشار اینترنتی دارید**، `cloudflared` را از [دستور رسمی](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/) دستی نصب کنید. سرور را با `./run.sh` در یک ترمینال محلی اجرا کنید؛ در ترمینال دوم:

```bash
./tunnel.sh quick
```

اسکریپت loopback بودن و درخواست احراز هویت را بررسی می‌کند و چیزی نصب نمی‌کند. فقط از **URL با HTTPS** چاپ‌شده توسط cloudflared و همان اطلاعات Basic/Bearer استفاده کنید. URL موقتی به‌تنهایی کنترل دسترسی نیست. توقف تونل با **Ctrl+C**؛ پنل محلی همچنان اجرا می‌شود. Cloudflare نقطهٔ پایان TLS و یک مرز اعتماد اضافی است. برای تونل نام‌دار پایدار از [راهنمای رسمی](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/get-started/) پیروی کنید؛ پروژه نصب خودکار تونل نام‌دار ندارد.

## API رسمی؛ محصول جداگانه

مستندات: <https://notrack.ai/api/docs>؛ نشانی پایه **`https://api.notrack.ai/v1`**؛ مدل **`notrack-uncensored`** با **کلید واقعی و پولی جداگانهٔ NoTrack**. توکن پنل، کلید رسمی نیست. محدودیت‌ها و مشاهدات گفت‌وگوی وب این پروژه را به API رسمی، قیمت‌گذاری یا تضمین‌های آن تعمیم ندهید.

## تنظیمات، بررسی و نگهداری

`PANEL_TOKEN` اجباری است. پیش‌فرض‌ها: `HOST=127.0.0.1`، `PORT=8080`، `PANEL_DATA=./data` و `PANEL_PACE=5.0` ثانیه. پس از تغییر، سرور را دوباره اجرا کنید. در صورت افشای توکن، در `.env` با مقدار تصادفی قوی جایگزین کنید، کلاینت‌ها و متغیرهای محیطی دارای اولویت را به‌روز و سرور/کانتینر را restart کنید.

در محیط مجازی توسعه:

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
node --check static/app.js
node --test tests/test_frontend.cjs
bash -n install.sh run.sh tunnel.sh
```

CI با pip معمولی روی Python **3.11 و 3.12** تست‌های استاندارد `unittest`، تست آفلاین رابط با Node و بررسی نحو JavaScript/Bash را اجرا می‌کند. هنگام آماده‌سازی انتشار، نصب تمیز در محیط مجازی موقت Python 3.12، نصب مجدد با حفظ `.env` و بررسی اجرای محلی و احراز هویت موفق بود. پیش‌بررسی تونل با فرمان ساختگی cloudflared آزموده شد، نه با تونل عمومی. این بررسی‌ها اثبات کارکرد فعلی مدل بالادستی، ویندوز/macOS، systemd یا ساخت Docker نیستند.
